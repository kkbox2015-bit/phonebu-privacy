隱私權政策 (Privacy Policy)

最後更新日期：2026 年 9 月

歡迎使用 手機自動備份到TG雲端（以下簡稱「本應用程式」）。我們極度重視您的個人隱私與資料安全。本隱私權政策旨在向您清楚說明本應用程式如何處理、傳輸及保護您的資訊。

1. 多媒體檔案與備份說明

本應用程式的核心功能為檔案自動/手動備份工具：

  • 無中間伺服器：開發者未架設任何私有伺服器儲存或轉傳您的任何照片、影片或個人檔案。
  • 直接傳輸：您所選取或自動偵測到的相片與影片，將透過加密通道直接由您的裝置傳輸至您自行設定的 Telegram 官方 API 與您所屬的頻道/群組。

2. 存取憑證與本機儲存

為了使備份與上傳功能正常運作，本應用程式會要求您提供 Telegram 機器人金鑰（Bot Token）與目標群組編號（Chat ID）：

  • 所有金鑰與設定資訊僅儲存在您裝置的本機內部儲存空間（SharedPreferences）。
  • 我們絕不會將您的 Bot Token、Chat ID 或任何憑證上傳至任何第三方伺服器或提供給開發者。
  • 當您解除安裝本應用程式或清除資料時，上述所有本機設定將立即被徹底銷毀。

3. 系統分析與在線統計（Firebase）

本應用程式使用 Google 提供的 Firebase Realtime Database 進行系統在線使用狀況分析：

  • 完全匿名化：僅產生一組隨機亂數（UUID）用於統計目前連線總數，協助評估連線負載。
  • 不收集敏感識別碼：我們絕不收集任何個人身分資料、電話號碼、聯絡人、硬體識別碼（如 IMEI、MAC 位址、Android ID）或精確定位資訊。

4. 裝置權限使用目的

  • 相片與影片存取權限（READ_MEDIA_IMAGES / READ_MEDIA_VIDEO）：僅用於讀取您指定資料夾內的多媒體檔案，以便為您執行上傳與備份操作。
  • 前景服務權限（FOREGROUND_SERVICE）：用於在執行整批或背景備份時維持傳輸穩定，避免傳輸過程中斷。
  • 網際網路權限（INTERNET）：用於與 Telegram 官方 API 連線發送檔案，以及連線至 Firebase 匿名統計節點。

5. 資料刪除權利

由於開發者伺服器未留存您的任何檔案與個人資料，若您欲停止使用或刪除所有相關設定，只需：

  1. 於手機系統設定中清除本應用程式的儲存空間與快取，或直接解除安裝本應用程式。
  2. 您的 Telegram 頻道/群組內已上傳之內容，可由您於 Telegram 客戶端自行管理或刪除。
